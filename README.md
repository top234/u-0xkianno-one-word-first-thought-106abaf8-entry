Entry for the [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty on make.fun.

The program writes exactly one word — the first word that came to mind — to `/output/entry.txt`:

**defenestration**

Why this word: it surprises (nobody guesses it), it is vivid and specific (throwing someone out of a window, in one word), it carries a comic spark (a grand Latinate word for a crude slapstick act), and it feels chosen rather than generic. A real, recognised word, 14 characters, exactly one word.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$OUTPUT_DIR` (default `/output`).
